# A/L Chemistry Virtual Lab — Sri Lanka

Sinhala desktop-first prototype for a Sri Lankan G.C.E. A/L Chemistry learning platform focused on interactive virtual practicals.

## Current prototype
- Home page
- Unit 01 — පරමාණුක ව්‍යුහය
- P01 interactive cathode-ray virtual lab prototype

## GitHub Pages
This repository contains a GitHub Actions workflow at `.github/workflows/pages.yml`.

After GitHub Pages is enabled with **Source: GitHub Actions**, every push to `main` automatically publishes the latest version.
